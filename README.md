# 班组周排班管理系统

本项目是本地运行的网页版班组排班工具，支持成员库、地点库、周排班、冲突校核、未安排人员自动归入仓前基地、人员视图和 Excel 导出。

## 运行

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可使用。

## 功能

- 班组成员新增、编辑、停用、删除、上移、下移、移动到指定位置。
- 工作地点新增、编辑、停用、删除、排序；仓前基地默认保留且不可删除。
- 选择任意日期自动切换到所在周，也可手动选择开始和结束日期。
- 新增、编辑、复制任务，支持同地点同日多任务。
- 自动校核同一人员同一天安排到多个地点的冲突。
- 自动统计每日未排班启用成员，并生成仓前基地“基地办公”内容。
- 地点视图和人员视图双视角预览。
- 使用 SheetJS 导出标准 Excel 排班表。

## 本地数据

所有数据保存在浏览器 `localStorage` 中，键名为 `team-scheduling-system-v2`。点击页面右上角“恢复示例数据”可重新写入默认成员、默认地点和示例任务。

## 说明

第一版为单机本地版，不包含登录、后端数据库、云同步和多人协作。
